# Lineage

**The consoles you grew up with, the way you remember them.**

Hi, I'm kurolume :wave: Welcome to **Lineage**, my attempt at a faithful interface for emulators. Switch it on and you get the console's own start-up, menus, memory cards and sounds, rebuilt screen by screen. Nothing of Sony's is included: the artwork, fonts and sounds are read from your own BIOS.

## What's out

| Release | What you get | Runs on |
|---|---|---|
| [Lineage PS2 for PS5](https://github.com/lineage-shell/lineage-ps2-for-ps5) | The opening with the towers, the main menu, the Browser, System Configuration, a Library, and the "PlayStation 2" logo before every game | PS5SX2 |
| [Lineage PS1 for PS5](https://github.com/lineage-shell/lineage-ps1-for-ps5) | The Sony and PlayStation start-up, memory cards, the CD Player in-game menu, the grey settings, and a Library | SwanStationPS5 |

Both need a jailbroken PS5 and your own BIOS. Each repo lists exactly what to install.

## Where it's going

In the future, I'd like to run the same design across PC emulators, from one shared core, and to support every BIOS version and region rather than just the ones I own. There's a lot of research and QA before we get there though!

## Want to help?

I've only got a couple of hours a week for this, so if you want to support and put some time in, drop me a line (@kurolume). That can be design or development. Whatever floats your boat :)

Testing with other BIOS versions and reporting what looks off is a big help too. Open an issue in the repo you're using.
